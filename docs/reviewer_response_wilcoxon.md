# Reviewer Response: Statistical Significance Analysis

Following the reviewer's suggestion, we expanded the statistical analysis beyond AST and conducted Wilcoxon signed-rank tests between the proposed model and all major baseline methods (ResNet-50, ViT, EfficientNet, ConvNeXt, and AST) using fold-wise cross-validation results from repeated 5-fold evaluation. A new statistical significance table and dedicated discussion subsection have been added to the manuscript. The results demonstrate that the proposed model achieves statistically significant improvements over competing approaches.
